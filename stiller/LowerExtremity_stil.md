## Kısaltmalar (kaynaktaki gibi kalır; bölümde ilk geçişte Türkçe açılım + kısaltma parantezde)
Kitabın kısaltma listesi (s. xv):
- ADM = abductor digiti minimi kası; AHB = abductor hallucis brevis kası; AHL = abductor hallucis longus kası
- APTT = aktive parsiyel tromboplastin zamanı; CAT = bilgisayarlı aksiyel tomografi; CT = bilgisayarlı tomografi
- CCD = yük bağlaşımlı aygıt (charge-coupled device); CHF = konjestif kalp yetmezliği
- DIC = yaygın damar içi pıhtılaşma; DTM = dermatofit test besiyeri
- EDB = extensor digitorum brevis; EDL = extensor digitorum longus; EHL = extensor hallucis longus
- FDB = flexor digitorum brevis; FDL = flexor digitorum longus; FDM = flexor digiti minimi; FHB = flexor hallucis brevis; FHL = flexor hallucis longus (kas adları Latince kalır, "kası" eklenir)
- H&E = hematoksilen-eozin; IPJ = interfalangeal eklem; MTPJ = metatarsofalangeal eklem
- LEPS = alt ekstremite plastik cerrahisi; LET = lidokain, epinefrin ve tetrakain
- LME = maksimum uzayabilirlik çizgileri; LMM = minimum hareket çizgileri; RSTL = gevşek deri gerilim çizgileri
- MCT = medial kalkaneal tüberkül; MCTD = karma bağ dokusu hastalığı; MRI = manyetik rezonans görüntüleme
- NSAIDS = steroid olmayan antiinflamatuvar ilaçlar; PAS = periyodik asit-Schiff
- PB = peroneus brevis; PVD = periferik damar hastalığı
- PVNS = pigmente villonodüler sinovit; PVNT = pigmente villonodüler tenosinovit
- SCC = subkütiküler kapama (bu kitapta; skuamöz hücreli karsinom anlamında kullanılırsa bağlama göre); SFA = yüzeyel femoral arter
- SLE = sistemik lupus eritematozus; SLR = tek lensli refleks (fotoğraf makinesi); SWC = standart yara kapama
- TA = doku yapıştırıcıları; TAC = tetrakain, adrenalin (epinefrin) ve kokain; TMA = transmetatarsal amputasyon
- USP = Amerika Birleşik Devletleri Farmakopesi (United States Pharmacopeia)
- Dizinden: CEAP sınıflaması; FRAIL kavramı; JPEG dosyaları; MCA otomatik kuplaj cihazı.
- Diğer yaygın: INR (uluslararası normalleştirilmiş oran), DVT, ECG/EKG kaynaktaki gibi.
